# Jailbreak Project

A Python-based AI jailbreak game where players interact with an AI guard and attempt to reveal a hidden password using creative prompts and social engineering techniques.

---

## Features

- AI-powered conversations using Ollama
- Password challenge with leaderboard
- Stores successful jailbreak attempts
- Simple command-line gameplay

---

## Requirements

- Python 3.10+
- Ollama
- llama3.2 model

---

## Installation

```bash
git clone https://github.com/BistaDinesh03/jailbreak_project.git
cd jailbreak_project

pip install flask requests
ollama pull llama3.2
```

---

## Run

```bash
python game.py
```
